Allmiibo Dateimanager 3.66.1 · Transfer Test 3

Deutsch

Entpacke die gesamte ZIP in einen eigenen Ordner. Starte dort
Start-Dateimanager.cmd und öffne den Dateimanager in Chrome oder Edge.
Oben bei der Browserversion steht „3.66.1 · Transfer Test 3“.
Der lokale Start setzt Python 3.8 oder neuer voraus.
Stop-Dateimanager.cmd beendet den lokalen Server.

Zum Direktstart mit sichtbarem Serverfenster verwende
Start-Dateimanager-Direkt.cmd. Öffne die dort angezeigte Adresse
im Browser. Strg+C im Serverfenster beendet diesen Direktstart.

Beim Upload in einen bereits vorhandenen Zielordner kann der Dateimanager
kleine, neue Unterordner einzeln prüfen und vollständig freigeben. Bei einem
Abbruch prüft er die Dateien vor dem Fortsetzen erneut. Vorhandene oder
schreibgeschützte Inhalte behalten ihre Metadaten.

Im Test mit 1.081 Dateien (658.806 Byte) wurden im Speichermodell aus
6.232 Ordnerabfragen 795. Nach einem simulierten Abbruch nach dem 33.
kleinen Schreibvorgang waren nach Wiederaufnahme und erneutem Einbinden
alle 1.081 SHA-256-Prüfsummen und die jeweils 128 Metadatenbytes korrekt.
Die Uploadzeit über Bluetooth am LCD für Test 3 steht noch aus.

Der übernommene Lesepfad brauchte an einem LCD unter Windows Chrome für
24 Dateien (12.960 Byte) im Mittel 9,08 Sekunden. Mochi brauchte für
dieselben Dateien 17,28 Sekunden. Das entspricht rund 47 % weniger Zeit.

Die beiliegende LCD-Firmware ist DE4.1 / App678. Der DFU-Updater nutzt die
in Test 2 geprüfte Wortausrichtung. Bestätigt Z21 das vollständige
142-Byte-Init-Paket, sendet er anschließend bis zu 140 Byte je Datenpaket.

English

Extract the entire ZIP to its own folder. Run Start-Dateimanager.cmd and
open the file manager in Chrome or Edge. The browser version at the top
reads “3.66.1 · Transfer Test 3”. Starting locally requires Python 3.8
or later. Stop-Dateimanager.cmd stops the local server.

For a foreground server, run Start-Dateimanager-Direkt.cmd, open the
address printed in its window, and press Ctrl+C there when finished.

When uploading into an existing folder, the file manager can verify and
publish small, newly created subfolders individually. After a disconnect,
it checks the files again before resuming. Existing and read-only contents
keep their metadata.

With 1,081 files (658,806 bytes), directory listings in the storage model
fell from 6,232 to 795. After a simulated disconnect following the 33rd
small-file write, all 1,081 SHA-256 digests and all 128 metadata bytes per
file matched after resuming and remounting. Timing the Test 3 upload over
Bluetooth on an LCD device remains pending.

On one LCD, the same read implementation on Windows Chrome took an average
of 9.08 seconds for 24 files (12,960 bytes). Mochi took 17.28 seconds for
the same files. That is about 47% less elapsed time.

The bundled LCD firmware is DE4.1 / App678. The DFU updater uses the word
alignment tested in Transfer Test 2. When Z21 confirms the full 142-byte
init packet, the updater subsequently sends up to 140 bytes per data write.
