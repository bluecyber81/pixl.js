Allmiibo Dateimanager 3.66.1 · Transfer Test 2

Deutsch

Entpacke die gesamte ZIP in einen eigenen Ordner. Starte dort
Start-Dateimanager.cmd und öffne den Dateimanager in Chrome oder Edge.
Oben bei der Browserversion steht „3.66.1 · Transfer Test 2“.
Der lokale Start setzt Python 3.8 oder neuer voraus.
Stop-Dateimanager.cmd beendet den lokalen Server.

Zum Direktstart mit sichtbarem Serverfenster verwende
Start-Dateimanager-Direkt.cmd. Öffne die dort angezeigte Adresse
im Browser. Strg+C im Serverfenster beendet diesen Direktstart.

Die Testausgabe enthält Änderungen für Übertragungen, Sammlungsprüfungen
und den DFU-Updater. Für einen Zeitvergleich verwende auf beiden Geräten
dieselbe Firmware-ZIP oder denselben Dateibestand und dieselbe Zielbelegung.
Die beiliegende LCD-Firmware ist DE4.1 / App678.
Beim DFU-Update sendet Test 2 Firmwaredaten in Vielfachen von vier Byte.
Bestätigt der Z21-Bootloader das 142-Byte-Init-Paket vollständig, verwendet
der Updater anschließend bis zu 140 Byte je Firmware-Schreibvorgang.

English

Extract the entire ZIP to its own folder. Run Start-Dateimanager.cmd and
open the file manager in Chrome or Edge. The browser version at the top
reads “3.66.1 · Transfer Test 2”. Starting locally requires Python 3.8
or later. Stop-Dateimanager.cmd stops the local server.

For a foreground server, run Start-Dateimanager-Direkt.cmd, open the
address printed in its window, and press Ctrl+C there when finished.

This test build includes changes to transfers, collection scans and the
DFU updater. To compare times, use the same firmware ZIP or files and
the same initial destination contents for each run.
The bundled LCD firmware is DE4.1 / App678.
During DFU, Test 2 writes firmware data in multiples of four bytes. If the
Z21 bootloader confirms the complete 142-byte init packet, the updater then
uses up to 140 bytes per firmware write.
