Allmiibo Dateimanager 3.55.6 · LCD DE3.84 und OLED Test 3

Deutsch
LCD-Testrelease für das Handy: https://github.com/bluecyber81/pixl.js/releases/download/de3.84-lcd-test1/Allmiibo_LCD_DE3_84_657_NUR_APP.zip
Ein Besitzer hat am 17.11.2026 den praktischen Betrieb von DE3.84/App657 mit Z21 bestätigt. Eine gezielt unterbrochene Android-Übertragung wurde nicht einzeln dokumentiert.
1. ZIP am Windows-PC vollständig entpacken. Start-Dateimanager.cmd mit
   installiertem Python ab 3.8 starten und Chrome oder Edge verwenden.
2. Für Dateien und Diagnose am Gerät „Bluetooth-Dateiübertragung“ öffnen.
   Die Fernbedienung verwendet eine separate Verbindung. Die Dateiübertragung
   zuerst beenden, BLE-Fernbedienung am Gerät aktivieren und dann im Browser
   „Fernbedienung“ öffnen.
3. Mit DE3.81-OLEDt3 liest der Dateimanager auch die Startphasen des nativen
   Dateisystems, die verfügbaren Akkuwerte und die erkannte Flash-Kennung.
   Im gepufferten Menü kann ein Displayfoto aufgenommen werden. Bei einem
   direkt zeichnenden Spiel das Spiel verlassen und erneut aufnehmen.
4. LCD DE3.82 bis DE3.84 melden beim letzten Einbinden von PackedFS die zugeteilten
   und gefüllten Cache-Seiten. Der Dateimanager zeigt die Werte unter
   Gerät und Diagnose → Startzeiten. Die Trefferquote berücksichtigt nur
   cachegeeignete Zugriffe. Bei alten Startberichten bleiben die
   tatsächlich verfügbaren Werte sichtbar. Die lokale Platzprüfung erkennt
   DE3.82 / App655, DE3.83 / App656 und DE3.84 / App657 anhand von Version, Zähler und PFS1-Speicherprofil.
   Für ein LCD-Foto ein Tiny-Spiel verlassen und das Menü aufnehmen. Während
   eines Spiels kann die Fotofunktion belegt sein oder die Anfrage ablaufen.
5. DE3.84 meldet unter „Firmwarekennung und Fehlernotiz“ das einkompilierte
   Boardprofil, die SourceID und ggf. eine Fehlernotiz vom vorigen Lauf.
   Die SourceID gehört zur laufenden App. Die frühere Fehlernotiz hat keine eigene Buildkennung. Der App-BIN-Hash gehört zum Referenzpaket.
6. Unter „Geführte Geräteprüfung → LCD-Prüfungen“ stehen 40 Fälle für Drehung,
   Tasten, vier Tiny-Spiele, Hinterleuchtung und DFU-Wiederaufnahme bereit.
   Lege die Ergebnisquelle fest und speichere deine Beobachtung. Importe
   zählen als übernommene Einträge. Die Prüfung sendet keine Gerätebefehle.
7. Stop-Dateimanager.cmd beendet den lokalen Server. Die Handy-Firmware für
   OLED Test 3 ist eine separate, signierte App-ZIP. Die Links für öffentliche
   Veröffentlichungen führen weiterhin zum jeweils dort genannten Stand.

English
LCD test release for your phone: https://github.com/bluecyber81/pixl.js/releases/download/de3.84-lcd-test1/Allmiibo_LCD_DE3_84_657_NUR_APP.zip
An owner reported successful practical use of DE3.84/App657 with Z21 on 17 November 2026. An intentionally interrupted Android update was not separately documented.
1. On Windows, extract the complete archive. With Python 3.8 or later
   installed, run Start-Dateimanager.cmd and use Chrome or Edge.
2. Open Bluetooth file transfer on the device for files and diagnostics.
   For remote control, leave file transfer, enable BLE remote in the device
   settings and open Remote control in the browser.
3. DE3.81-OLEDt3 adds native filesystem startup phases, available battery
   readings and the detected flash ID. Capture a screenshot from a buffered
   menu. If a game draws directly to the display, leave the game and retry.
4. LCD DE3.82 through DE3.84 report allocated and filled cache pages at the end of the
   last PackedFS mount. Open Device and diagnostics → Startup times to
   view the readings. The hit rate covers cache-eligible reads only.
   Older startup reports still show the measurements they contain. The local
   capacity check recognizes DE3.82 / App655, DE3.83 / App656 and DE3.84 / App657 by their exact version, counter
   and PFS1 profile. To take an LCD screenshot, exit any Tiny game and capture
   the menu. During a game the capture can be busy or time out.
5. With DE3.84, Firmware identity and fault note shows the compiled board,
   SourceID and any retained fault from the previous application run. The
   SourceID belongs to the running app. The previous note has no build ID of its own. The application image hash is a reference-package value.
6. In Guided device check → LCD checks, 40 cases cover rotation, buttons,
   four Tiny games, backlight and both DFU resumption stages. Select the
   result source before recording each observation. Imported results are
   marked separately. Entering results sends no commands to the device.
7. Run Stop-Dateimanager.cmd to stop the local server. The signed OLED Test 3
   phone firmware is a separate application ZIP. Links to public releases
   still point to the versions named there.
