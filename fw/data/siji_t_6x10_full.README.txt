found in application C/H sources, including optional apps. Each retained
glyph record is copied exactly; font metrics and ASCII lookup data stay
unchanged. Unicode lookup indices are rebuilt in groups of at most 32 glyphs.

review of their complete value range. All current dynamic list icons were
traced to the included constants. User text uses the separate WQY font,
which this optimization does not alter.

for pixels, advance/size/offset metrics and missing-codepoint lookup bounds.
